Chapter 5 — Timeouts

Example:

Suppose a command hangs forever.

Jarvis shouldn't freeze.

It should terminate the command after a timeout.

Chapter 7 — Working Directory

Example:

subprocess.run(
    ["git", "status"],
    cwd="/home/prajwinkj/Jarvis"
)

Jarvis can execute commands in any folder without changing its own current directory.

Chapter 8 — Popen

This is where things become really interesting.

Unlike run():

subprocess.Popen(...)

starts a process and immediately returns control.

Examples:

Launch Chrome
Launch VS Code
Launch Spotify

Jarvis keeps running while those applications stay open.
