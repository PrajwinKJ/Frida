One thing I would add that many people overlook

You're aiming to build something that will grow over months or years. That makes software architecture almost as important as programming.

Start learning:

Project structure
Design patterns (Factory, Observer, Strategy, Command)
Dependency injection (at least the concept)
Event-driven architecture
State machines

These directly affect whether your project stays manageable as it grows.

What I would not spend time on right now
❌ React (unless you want to become a frontend developer)
❌ CSS animations
❌ Game development
❌ TensorFlow/PyTorch from scratch
❌ Kubernetes
❌ Microservices (far too early)
❌ C++ (until you hit a real limitation with Python/C)
