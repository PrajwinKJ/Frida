Things Android allows

Without root you can generally do:

✅ Battery percentage

✅ Clipboard

✅ Vibrate

✅ Flashlight

✅ Notifications

✅ Send notifications

✅ Play media

✅ Record microphone (with permission)

✅ Camera (with permission)

✅ GPS

✅ Contacts (permission)

✅ SMS (permission)

✅ Call logs (permission)

✅ Installed apps

✅ Files

✅ Wi-Fi information

✅ Bluetooth

Things Android restricts

For security, apps generally cannot:

❌ Tap anywhere on screen

❌ Press arbitrary buttons

❌ Read every app's data

❌ Read WhatsApp chats directly

❌ Read banking apps

❌ Unlock phone

❌ Install apps silently

If you want automation

Android provides an Accessibility Service.

This is how apps like

Tasker
MacroDroid
Automate

perform actions.

It can

press buttons
scroll
click
type text
inspect UI elements

Google reviews apps using Accessibility carefully, so it should only be used for legitimate accessibility or automation purposes.
